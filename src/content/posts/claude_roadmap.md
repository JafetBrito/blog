## 📘 Tema 1: Conoce Claude AI

![Claude interface on laptop](https://images.unsplash.com/photo-1620712943543-bcc4688e7485?w=800&q=80)

Claude es la IA conversacional creada por **Anthropic**, una empresa de seguridad en IA fundada en 2021 por ex-investigadores de OpenAI — incluyendo a Dario Amodei y Daniela Amodei.

Lo que hace único a Anthropic es su filosofía fundacional: la empresa fue creada con la premisa de que la IA avanzada **puede ser peligrosa**, y que la mejor manera de reducir ese riesgo es estar en la vanguardia del desarrollo — pero hacerlo de forma responsable.

**La línea del tiempo rápida:**

* 🗓️ **2021** — Fundación de Anthropic
* 🗓️ **Marzo 2023** — Lanzamiento de Claude 1 (solo API)
* 🗓️ **2024** — Claude 3 (Haiku, Sonnet, Opus) llega al público
* 🗓️ **2025** — Claude 3.5, Extended Thinking, Claude Code, MCP
* 🗓️ **2026** — Claude 4.x (Haiku 4.5, Sonnet 4.6, Opus 4.8), **Fable 5**, Cowork, Skills

**Los planes disponibles hoy:**

| Plan | Precio | Para quién |
|---|---|---|
| **Free** | $0 | Uso casual — memoria, web search, Sonnet 4.6 |
| **Pro** | ~$20/mes | Usuario frecuente — más mensajes, Extended Thinking |
| **Max** | $100-200/mes | Power user — Opus, límites máximos, Cowork |
| **Team** | ~$30/seat | Equipos — espacios compartidos |
| **Enterprise** | Custom | Organizaciones — compliance, SSO, privacidad |

> 💡 **El tier gratuito en 2026 es sorprendentemente generoso:** incluye memoria persistente, búsqueda web, artefactos y acceso a Sonnet 4.6. No actualices hasta que sientas el límite real.

## 🧬 Tema 2: Qué es Claude y Qué Lo Hace Diferente

Claude no es "otro ChatGPT". Las diferencias son filosóficas y técnicas:

### 🛡️ Constitucional AI — La Ética Integrada en el Modelo

Anthropic desarrolló una técnica llamada **Constitutional AI**: en lugar de solo filtrar outputs problemáticos *después* de generarlos, Claude fue entrenado con un conjunto de **principios éticos integrados** en su proceso de razonamiento. Claude no solo evita el daño — está diseñado para querer evitarlo.

### 🎯 Las 3 Palabras que Definen a Claude

Anthropic describe a Claude con tres palabras: **Helpful, Harmless, Honest**. Y en la práctica:

* 🤝 **Helpful:** No te da respuestas vagas para "estar seguro" — intenta ser genuinamente útil, incluso en temas complejos
* 🔒 **Harmless:** Tiene límites claros, pero no está sobre-restringido para preguntas legítimas
* ✅ **Honest:** Admite cuando no sabe algo o cuando puede estar equivocado — no alucina con confianza falsa

### 📊 Lo Que Claude Hace Mejor que la Competencia

* 📝 **Escritura larga y coherente** — mantiene el hilo en textos de miles de palabras
* 🔍 **Análisis de documentos complejos** — PDFs técnicos, contratos, reportes financieros
* 💻 **Código con razonamiento** — no solo completa código, explica el *por qué*
* 🔐 **Seguridad y privacidad** — Anthropic tiene las políticas de datos más estrictas entre los grandes modelos
* 🧠 **Razonamiento nuanced** — maneja ambigüedad y matices mejor que la mayoría

### ⚠️ Lo Que Claude NO Hace

* ❌ No genera imágenes (usa Midjourney/DALL-E para eso)
* ❌ No genera audio ni video
* ❌ No tiene acceso a internet en tiempo real *por defecto* (debes activar la búsqueda web)

## ⚖️ Tema 3: Elegir Haiku, Sonnet u Opus — La Guía Definitiva

Esta es la pregunta que más confunde a los usuarios nuevos. La respuesta corta: **Sonnet para casi todo, Haiku para velocidad, Opus para los problemas más difíciles de tu vida**.

![Model comparison diagram](https://images.unsplash.com/photo-1551288049-bebda4e38f71?w=800&q=80)

### La Metáfora del Taller

Imagina que tienes tres herramientas:

* 🔧 **Haiku** = Destornillador eléctrico → Rápido, ligero, perfecto para tareas repetitivas
* 🔨 **Sonnet** = Taladro inalámbrico → El balance perfecto para 90% del trabajo
* ⚙️ **Opus** = Torno industrial → Overkill para la mayoría, indispensable para los proyectos grandes

### La Comparativa Real (2026)

| | Haiku 4.5 | Sonnet 4.6 | Opus 4.8 | Fable 5 |
|---|---|---|---|---|
| **Velocidad** | ⚡⚡⚡⚡⚡ | ⚡⚡⚡⚡ | ⚡⚡⚡ | ⚡⚡ |
| **Calidad** | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 🌟🌟🌟🌟🌟 |
| **Costo (API)** | 💰 | 💰💰 | 💰💰💰 | 💰💰💰💰 |
| **Contexto** | 200k tokens | 1M tokens | 200k tokens | 1M tokens |
| **Ideal para** | Tareas simples, alto volumen | Uso diario, todo tipo | Análisis complejo | Long-horizon tasks |

### El Árbol de Decisión

```
¿Qué necesitas hacer?
        │
        ├─► Respuesta rápida / clasificación / traducción simple
        │   └─► 🔧 HAIKU — máxima velocidad
        │
        ├─► Escritura, análisis, código, conversación general
        │   └─► 🔨 SONNET — tu caballo de batalla diario
        │
        ├─► Análisis profundo / estrategia / investigación
        │   └─► ⚙️ OPUS — cuando la calidad importa más que la velocidad
        │
        └─► Tareas de días / codebases enormes / proyectos científicos
            └─► 🌟 FABLE 5 — la nueva frontera (ver nuestro artículo dedicado)
```

> 💡 **Tip de power user:** En la API, nunca fijes el modelo a una versión específica como `claude-opus-4-6` — usa el alias `claude-opus-latest` para recibir automáticamente las mejoras sin cambiar tu código.

## ✍️ Tema 4: Cómo Armar Prompts Efectivos en Claude

> Ver nuestra [**Guía Completa de Prompt Engineering**](/blog/gigo-prompt-engineering-guide) para el tratamiento exhaustivo. Aquí el resumen ejecutivo específico para Claude.

Claude tiene características específicas que lo hacen responder mejor a ciertos estilos de prompting:

### Lo Que Claude Ama ❤️

```xml
<!-- Claude entiende y sigue XML tags con alta fidelidad -->
<tarea>Analiza este contrato</tarea>
<contexto>Soy abogado corporativo, cliente es startup SaaS</contexto>
<formato>Bullet points por cláusula de riesgo</formato>
<documento>
[texto del contrato aquí]
</documento>
```

* ✅ **XML tags** — Claude fue entrenado extensamente con XML, lo sigue con altísima precisión
* ✅ **Instrucciones al principio** — Las instrucciones antes del contenido tienen más peso
* ✅ **Delimitadores claros** — Separa instrucciones de datos con tags o lineas
* ✅ **Ejemplos concretos** — Few-shot funciona muy bien con Claude

### Lo Que Claude NO Ama 😬

* ❌ **ALL CAPS agresivo** — "NUNCA HAGAS ESTO" — degrada la calidad del output
* ❌ **Instrucciones contradictorias** — Claude intentará resolver la contradicción pero puede fallar
* ❌ **Prompts vagos** — "Ayúdame con esto" sin contexto → respuesta genérica garantizada

### La Plantilla Mínima Efectiva para Claude

```
Rol: [Quién eres / qué experto necesitas]
Contexto: [Situación actual, restricciones, nivel técnico]
Tarea: [Qué específicamente necesitas]
Formato: [Cómo quieres la respuesta]

[CONTENIDO / DATOS AQUÍ]
```

## 🔍 Tema 5: Cómo Activar Búsqueda Web en Claude

![Web search toggle illustration](https://images.unsplash.com/photo-1519389950473-47ba0277781c?w=800&q=80)

Por defecto, Claude solo tiene acceso al conocimiento de su entrenamiento (hasta enero 2026). Para preguntas sobre eventos recientes, precios actuales, o cualquier cosa que cambia — necesitas activar la búsqueda web.

### ¿Cómo Activarla?

**En Claude.ai:**
1. Abre una conversación nueva
2. Busca el ícono 🌐 o el toggle de herramientas en la barra inferior
3. Activa "Search the web" — verás el ícono iluminarse

**Desde Settings → Feature Preview:**
* Puedes activarla de forma persistente para todas las conversaciones

### Cuándo Usarla (y Cuándo No)

| Úsala para | No la necesitas para |
|---|---|
| Noticias y eventos recientes | Conceptos atemporales |
| Precios de productos | Historia conocida |
| Lanzamientos de software | Código y algoritmos |
| Estadísticas actualizadas | Análisis de tus documentos |
| ¿Quién es el CEO de X ahora? | Explicaciones matemáticas |

> ⚠️ **Nota Zero Trust:** Cuando Claude busca en la web, los resultados son datos externos — aplica el mismo escepticismo que aplicarías a cualquier fuente. Claude cita sus fuentes; verifica las importantes.

## 🧠 Tema 6: Pensamiento Extendido en Claude

El **Pensamiento Extendido** (Extended Thinking) es la característica más poderosa de Claude para usuarios que necesitan razonamiento profundo — y la más subutilizada.

### ¿Qué es Exactamente?

En modo normal, Claude genera una respuesta directamente. Con Extended Thinking activado, Claude primero **razona internamente durante un tiempo prolongado** — explorando múltiples enfoques, revisando su propia lógica, identificando errores — antes de darte la respuesta final.

Piénsalo así:

```
Modo Normal:     Pregunta → 💬 Respuesta
                 (2 segundos, razonamiento implícito)

Extended Thinking: Pregunta → 🧠🧠🧠 Razonamiento profundo → 💬 Respuesta
                   (30-120 segundos, mucho más preciso)
```

### Cuándo Vale la Pena Esperar

* 📐 **Matemáticas y lógica complejas** — problemas con múltiples pasos
* ⚖️ **Análisis legal o estratégico** — donde los matices importan
* 🔬 **Investigación técnica** — que requiere considerar múltiples perspectivas
* 🏗️ **Diseño de sistemas** — arquitecturas complejas con trade-offs
* 🐛 **Debugging difícil** — cuando el error no es obvio

### Cómo Activarlo

En Claude.ai, busca el ícono 🧠 o el toggle "Extended thinking" antes de enviar tu mensaje. Solo disponible en planes Pro, Max y Enterprise.

> 💡 **Tip:** No actives Extended Thinking para preguntas simples — es como usar un bisturí para cortar pan. Guárdalo para cuando el problema genuinamente lo requiera.

## 🔬 Tema 7: Deep Research en Claude

**Deep Research** lleva el pensamiento extendido un paso más allá: Claude no solo razona más profundo, sino que **ejecuta múltiples búsquedas web, lee fuentes, y sintetiza todo** en un reporte estructurado — de forma autónoma.

![Research visualization](https://images.unsplash.com/photo-1507003211169-0a1dd7228f2d?w=800&q=80)

### El Proceso Detrás de Escena

```
Tu pregunta
     ↓
Claude formula 5-10 queries de búsqueda relevantes
     ↓
Ejecuta las búsquedas simultáneamente
     ↓
Lee y evalúa cada fuente encontrada
     ↓
Identifica contradicciones y gaps
     ↓
Sintetiza en un reporte estructurado con citas
     ↓
Resultado: 5-15 minutos después, un análisis de investigador
```

### Cómo Usarlo Bien

```
❌ Mal uso:
"Investiga IA"

✅ Buen uso:
"Haz una investigación profunda sobre el estado actual
de los modelos de lenguaje para aplicaciones de diagnóstico
médico. Necesito: panorama de jugadores principales,
regulaciones FDA/EMA actuales, casos de uso aprobados,
y los principales riesgos identificados por la comunidad
científica. Audiencia: directorio de hospital regional."
```

### Disponibilidad

Deep Research está disponible en planes **Pro, Max, Team y Enterprise** (no en el tier gratuito).

## 📄 Tema 8: Análisis de Documentos e Imágenes con Claude

Esta es una de las capacidades más prácticas y menos exploradas de Claude. Puedes cargar **PDFs, Word docs, imágenes, spreadsheets, código** y Claude los analiza en contexto.

### 📑 Documentos — Lo Que Puedes Hacer

Tipos de archivos soportados: PDF, DOCX, TXT, MD, código fuente, CSV

**Casos de uso reales:**

* 🔍 "Analiza este contrato de 80 páginas y dame las 5 cláusulas con mayor riesgo para el cliente"
* 📊 "Lee este reporte financiero y compara el Q3 2025 vs Q3 2024"
* 🐛 "Aquí está el codebase completo. Encuentra vulnerabilidades de seguridad"
* 📚 "Resume este paper académico para una audiencia no técnica"
* ✉️ "Extrae todos los action items de esta cadena de emails"

### 🖼️ Imágenes — Lo Que Puedes Hacer

Claude tiene visión nativa — puede analizar cualquier imagen que subas.

**Casos de uso reales:**

* 📸 "¿Qué muestra esta gráfica? Dame los datos numéricos que puedas extraer"
* 🔧 "Aquí hay un screenshot del error. ¿Qué está fallando?"
* 🏗️ "Analiza este diagrama de arquitectura y sugiere mejoras"
* 🎨 "Describe este diseño de UI e identifica problemas de UX"
* 📝 "Transcribe el texto de esta foto de pizarrón"

### El Límite de Contexto Importa

Con Sonnet 4.6 y Fable 5, tienes hasta **1 millón de tokens** de contexto. Para referencia:
* 1M tokens ≈ 750,000 palabras ≈ los primeros 3 libros de El Señor de los Anillos
* Suficiente para analizar codebases enteros, reportes anuales completos, o múltiples PDFs a la vez

## 📊 Tema 9: Análisis de Excel con Claude y K-Means

![Data analysis visualization](https://images.unsplash.com/photo-1460925895917-afdab827c52f?w=800&q=80)

Este es el tema más técnico de la guía — y uno de los más poderosos para profesionales de datos.

### Claude para Excel: El Addon

Claude tiene una integración nativa con Microsoft Excel via **Claude for Excel** (addon). Con él puedes:

* 🔢 Generar fórmulas complejas describiéndolas en lenguaje natural
* 🧹 Limpiar datos sucios automáticamente
* 📊 Crear visualizaciones
* 🔍 Analizar datasets y encontrar patrones
* 🤖 Ejecutar análisis estadísticos sin código

### K-Means con Claude: Clustering para Todos

K-Means es un algoritmo de agrupación (clustering) que divide datos en K grupos basados en similitudes. Claude puede implementarlo directamente en Python o R y explicar los resultados.

**Ejemplo de prompt para K-Means:**

```
Tengo este dataset de clientes con columnas:
[edad, ingresos_anuales, frecuencia_compra, ticket_promedio]

1. Carga el CSV adjunto
2. Normaliza las variables
3. Aplica K-Means con K=4
4. Visualiza los clusters con matplotlib
5. Describe en lenguaje de negocio qué tipo de cliente
   representa cada cluster
6. Dame recomendaciones de marketing para cada segmento

[ADJUNTAR CSV]
```

**Claude generará el código Python completo, lo ejecutará, y te dará:**
* El script reutilizable
* Las visualizaciones
* La interpretación de negocio de cada cluster
* Recomendaciones accionables

## 📁 Tema 12: Proyectos en Claude — El Contexto que Nunca se Pierde

Los **Proyectos** son espacios de trabajo persistentes donde Claude recuerda el contexto de todo lo que has trabajado juntos en ese contexto — sin límite de tiempo.

### ¿Por Qué Importan?

Sin proyectos, cada conversación empieza desde cero. Con proyectos:

* 📚 Claude recuerda **todos los documentos** que subiste al proyecto
* 💬 Recuerda el **historial de conversaciones** del proyecto
* 🎭 Mantiene las **instrucciones de comportamiento** que definiste
* 🔗 Todo el equipo puede acceder al mismo contexto (en Team/Enterprise)

### Cómo Usar Proyectos Efectivamente

**Estructura recomendada por tipo de proyecto:**

```
📁 PROYECTO: Mi Empresa
```

Las **Skills** son instrucciones personalizadas que defines tú, guardadas como "habilidades especializadas" que Claude activa cuando las necesita. Es como darle a Claude un manual de operaciones específico para tus tareas.

### ¿Qué Son las Skills?

Una Skill es esencialmente un **documento de instrucciones** que le dice a Claude:
- Cómo abordar cierto tipo de tarea
- Qué herramientas usar y en qué orden
- Qué formato producir
- Qué restricciones respetar

### Ejemplo: Skill para Code Review

```markdown
# SKILL: Code Review de Seguridad

## Cuándo aplicar
Cuando el usuario pida revisar código o analizar
vulnerabilidades de seguridad.

## Proceso obligatorio
1. Analiza SIEMPRE en este orden: CRÍTICO → ALTO → MEDIO → BAJO
2. Para cada problema encontrado:
   - Línea exacta
   - Descripción del riesgo
   - CVSS score estimado
   - Código corregido
3. Termina con: veredicto (APROBADO/RECHAZADO) + resumen ejecutivo

## Herramientas a consultar
- OWASP Top 10 como referencia de categorías
- CWE para clasificación estándar

## Restricciones
- Nunca marcar como bajo riesgo un hardcoded credential
- Siempre incluir el fix, no solo el problema
```

### Cómo Crear Skills en Claude.ai

1. Ve a **Settings → Skills** (o "Custom Instructions")
2. Click en "Create New Skill"
3. Escribe el nombre, descripción, y las instrucciones detalladas

> 💡 **Para devs:** Si usas la API, las Skills se implementan como system prompts guardados con versión control. Tratalos como código — versionalos en Git.

```
                     (Agente autónomo, Claude ejecuta)
```

## ✍️ Topic 4: Effective Prompts in Claude

```xml
<task>Analyze this contract</task>
<context>I'm a corporate lawyer, client is a SaaS startup</context>

<document>
```

* ✅ **Instructions first** — Instructions before content carry more weight
* ✅ **Clear delimiters** — Separate instructions from data
* ✅ **Concrete examples** — Few-shot works very well with Claude

### What Claude Doesn't Love 😬
* ❌ **Aggressive ALL CAPS** — Degrades output quality
* ❌ **Contradictory instructions** — Claude will try to resolve but may fail
* ❌ **Vague prompts** — "Help me with this" → guaranteed generic response

### The Minimal Effective Template for Claude

```
Role: [Who you are / what expert you need]
Context: [Current situation, constraints, technical level]
Task: [What specifically you need]
Format: [How you want the response]

[CONTENT / DATA HERE]
```

## 🛠️ Topic 16: Custom Skills in Claude

A **Skill** is an instructions document that tells Claude: how to approach certain task types, which tools to use and in what order, what format to produce, and which constraints to respect.

**Example: Security Code Review Skill**

```markdown
# SKILL: Security Code Review

## When to apply
When user asks to review code or analyze security vulnerabilities.

## Required process
1. ALWAYS analyze in this order: CRITICAL → HIGH → MEDIUM → LOW
2. For each found issue:
   - Exact line number
   - Risk description
   - Estimated CVSS score
   - Corrected code
3. End with: verdict (APPROVED/REJECTED) + executive summary

## Constraints
- Never mark hardcoded credentials as low risk
- Always include the fix, not just the problem
```

**Creating skills in Claude.ai:**
1. Settings → Skills (or "Custom Instructions")
2. "Create New Skill"
3. Write name, description, and detailed instructions
4. Save — Claude will have it available in your conversations

## 🔑 The Key Isn't Claude — The Key Is You

We've covered 18 features. It can feel overwhelming. Before closing, here's the most important idea in this entire guide:

> **The gap between someone who gets mediocre results from Claude and someone who gets extraordinary results isn't in the features they use. It's in the quality of what they ask.**

Claude is Deep Thought. It's the most advanced computer ever built for you. But if you ask it "How do I improve my business?" you'll get **42**.

The right answer has nothing to do with activating more features or using bigger models. It has to do with:

* 🧠 **Knowing what you want** before writing the prompt
* 📍 **Giving the context** the model needs to be useful
* 🎯 **Being specific** about the real problem, not the generic version
* 🔁 **Iterating** when the first response isn't what you needed
* 🤝 **Treating Claude as a collaborator**, not a search engine

**The tools are neutral. What you do with them defines whether they're a calculator or a superpower.**
